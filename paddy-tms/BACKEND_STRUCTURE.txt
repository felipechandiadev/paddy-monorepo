1. Registrar Camión
   POST /api/v1/logistics/truck-receptions
   Request: { numero_turno, producer_id, patente, chofer_nombre, rut_chofer, guia? }
   Response: { success, message, data: TruckReception }

2. Registrar Pesaje
   POST /api/v1/logistics/weighings
   Request: { truck_reception_id, estado, peso_bruto?, peso_tara?, numero_ticket?, pdf_url? }
   Response: { success, message, data: TruckReception }

3. Listar Todas las Recepciones
   GET /api/v1/logistics/truck-receptions?limit=100&offset=0
   Response: { success, data: TruckReception[], total: number }

4. Obtener Recepción por ID
   GET /api/v1/logistics/truck-receptions/:id
   Response: { success, data: TruckReception }

5. Listar Recepciones por Productor
   GET /api/v1/logistics/producers/:producerId/truck-receptions?limit=100&offset=0
   Response: { success, data: TruckReception[], total: number }

6. Listar Recepciones por Estado
   GET /api/v1/logistics/truck-receptions/status/:status?limit=100&offset=0
   Response: { success, data: TruckReception[], total: number }

7. Actualizar Recepción
   PUT /api/v1/logistics/truck-receptions/:id
   Request: { patente?, chofer_nombre?, ... }
   Response: { success, message, data: TruckReception }

8. Cancelar Recepción
   DELETE /api/v1/logistics/truck-receptions/:id
   Response: { success, message, data: TruckReception }

9. Obtener Estadísticas
   GET /api/v1/logistics/stats/overview
   Response: { success, data: { total, finalizadas, enEspera, pesando } }
